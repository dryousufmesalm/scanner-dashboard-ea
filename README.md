# Scanner Dashboard EA

Multi-symbol/multi-timeframe scanner EA for MetaTrader 5.

**Author:** Yousuf Mesalm | www.yousufmesalm.com | WhatsApp +201006179048 | Upwork: https://www.upwork.com/freelancers/youssefmesalm

## Requirements

MetaTrader 5. YM library in MQL5/Include/YM if used.

## Installation

Copy ScannerDashboard.mq5 into MQL5/Experts/.

## Compilation

Compile in MetaEditor (F7). Include path must include terminal MQL5 folder.

## Usage

Attach to a chart. Use for multi-symbol/multi-timeframe scanning.
